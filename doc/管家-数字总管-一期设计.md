# 设计：管家——收件箱的数字总管（一期）

> 工坊需求流程交付物（评审通过、实现合入后删除本文件）。v2 按 owner 退回意见重写：一期聚焦**管家形象 + 界面 + 对话**的落地；机制深化（真 agent 大脑、需求工具、派活）二期讨论。

## 1. 背景与愿景

收件箱是需求的控制台，但它是一个**工具面板**——没有一个「人」在帮你统筹。管家 = 收件箱的数字总管：一个有形象、有名字、常驻的对话角色，你随时点开和它说话（给需求、问状态、聊想法），它在自己的地盘（总管文件夹）为你工作。

**分期**：
- **一期（本设计）**：总管文件夹 + 管家形象与入口动效 + 管家界面（顶部形象、底部对话框）+ 与管家的实时对话（大脑 v1 = 已配置的模型，管家 persona）
- **二期**：管家大脑升级为**真 agent**（claude code / opencode 在总管文件夹中常驻启动，带需求工具与派活能力）；数字人进阶（语音/动态形象）
- **三期+**：统筹机制深化（派活、多会话协调）——单独设计

## 2. 一期范围

### 2.1 总管文件夹（管家的家）

- 守护进程初始化时创建 **`~/plannotator-butler/`**（家目录下，一眼可见）。
- 用途：管家对话历史（`history.jsonl`）、管家会话状态（`state.json`：引擎/会话 id/ persona 版本）、后续二期 agent 的工作目录。
- 跨重启延续：对话历史与会话 id 持久化，管家「记得」之前聊过什么。

### 2.2 管家形象与入口

- 收件箱界面（窗口右下角）常驻一颗**管家悬浮球**：管家的视觉形象（一期：设计的管家视觉——礼帽+领结的管家徽标，待机时轻微呼吸动画）。
- 点击悬浮球 → **入场动效**（悬浮球放大展开为全屏管家界面，约 400ms 的缓动动画）。
- 管家界面关闭 → 收缩回悬浮球。

### 2.3 管家界面

- **顶部**：数字人形象区（一期：管家的视觉形象 + 待机微动画；说话时轻微律动。真·数字人视频/语音为后续版本）。
- **中部**：对话流（消息气泡，管家回复流式渲染）。
- **底部**：对话框（输入区 + 发送）。
- **风格**：沉浸式深色/主题跟随，无工坊列表等杂物——这一页就是你和管家的对话。

### 2.4 管家的大脑（v1）

- 复用现有 Ask 通道的 AI 会话机制（packages/ai：已配置的 provider/model，流式回复）——**快、流式、零新依赖**。
- **管家 persona**：一段管家角色提示词（称呼、语气、职责边界），随请求注入。
- 对话历史持久化在总管文件夹：跨重启延续；每条消息带时间戳。
- 工作目录：管家的 AI 会话 cwd = 总管文件夹（为二期真 agent 预留的地盘）。

### 2.5 入口动效细节

- 悬浮球（右下角，48px 圆形，管家徽标 + 呼吸光晕）
- 点击 → 球体放大 + 淡出 → 管家界面淡入 + 顶部形象从上滑入 + 对话框从下浮起（整体 ~400ms，cubic-bezier 缓动）
- 再次点击悬浮球/ESC → 收回

## 3. 实现清单

| 件 | 说明 |
| --- | --- |
| 守护进程初始化 | 创建 `~/plannotator-butler/`（存在则跳过） |
| `POST /api/inbox/butler/chat` | `{ message }` → 流式返回管家回复（AI 会话驱动，persona 注入，cwd=总管文件夹） |
| 对话持久化 | `~/plannotator-butler/history.jsonl`（追加式）+ `state.json`（AI 会话 id 延续） |
| 窗口：管家悬浮球 | 常驻右下角（窗口内组件，theme 跟随） |
| 窗口：管家界面 | 全屏覆盖层（形象区 + 对话流 + 输入区 + 入场/退场动效） |
| 形象素材 | 管家徽标 SVG（礼帽+领结）+ 呼吸/律动 CSS 动画 |

## 4. 一期边界（不做）

- 管家不做需求操作（读/改需求、派活）——二期真 agent 大脑 + 工具面再上
- 不接 Claude Code / opencode CLI（二期的大脑升级项）
- 不做语音/真数字人视频
- 不做多管家/多形象

## 5. 验收（一期）

1. 守护进程启动后 `~/plannotator-butler/` 存在。
2. 窗口右下角可见管家悬浮球（呼吸动画）。
3. 点击 → 动效展开管家界面（顶部形象、底部对话框）。
4. 发消息 → 管家流式回复（persona 生效：自称管家、语气符合人设）。
5. 重启守护进程 → 对话历史延续（管家记得上下文）。
6. ESC/关闭 → 收回悬浮球，再次点击可重新进入。
